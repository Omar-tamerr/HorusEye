HorusEye

See the path. Know the fix.

An AI-assisted Active Directory attack-path platform. It ingests BloodHound, Certipy, ldapdomaindump and NetExec output, then ranks every path by exploitability, proves it with evidence, and hands red teams the command and blue teams the remediation — in one portable, offline report.

Where it fits

BloodHound maps the graph.
HorusEye tells you what to do about it.

HorusEye doesn't replace your collectors — it consumes their output and turns a graph of relationships into a ranked, defensible plan of action for both sides of the engagement.

SharpHound / BloodHound Certipy NetExec → 𓂀 HorusEye → Ranked paths + evidence + fixes
What it does

One analysis, two audiences

Thirteen attack-path detections, scored by real exploitability — each with the evidence behind it, the command to validate it, and the fix and detection to close it.

🗺️

Shortest path to DA

A deterministic graph from any foothold to Domain Admin across membership, ACLs, local-admin, sessions, DCSync and delegation — with the command for each hop.

✂️

Remediation impact

Names the choke points — the single fixes that break the path with no alternative route remaining. Fix the right edge, not all of them.

🔎

Evidence & confidence

Every finding carries the exact ACEs/objects behind it, a confidence level, and the source file — so it's reproducible, not a black box.

🛡️

Built for defenders too

MITRE ATT&CK mapping, concrete remediation steps, and detection guidance (event IDs) on every finding. One report, red and blue.

🧭

Offline explorer

A single self-contained HTML file — dashboard, interactive attack graph, and filterable findings. No server, nothing leaves the file. Hand it to a client.

⚙️

CI-ready & private

--diff retests, --fail-on exit codes, byte-deterministic output, and --ai-redact to keep client names off any API. A stable Python API, too.

How it compares

Complementary, not a clone

HorusEye is built to sit alongside graph-exploration tooling like BloodHound, focused on the part that comes after the graph: triage, evidence, and remediation.

Get started

Install in one line

Python 3.8+ on Linux or Windows. The only runtime dependency is rich.

$pip install git+https://github.com/Omar-tamerr/HorusEye
$horuseye --bloodhound ./bh/ --domain corp.local --graph --explorer report.html
1 · Collect

Run SharpHound (-c All), Certipy or NetExec as you already do.

2 · Analyse

Point HorusEye at the output. Get ranked paths, evidence and fixes in seconds.

3 · Report

Ship the offline explorer, Markdown or JSON — or gate CI with --fail-on.
